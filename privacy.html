Privacy policy

Last updated: 23 October 2026

What the tool accesses

Japan Job Search uses Google's drive.file permission. That means it can only see and change the files it creates itself (a Google Sheet, a Drive folder and Google Docs). It cannot see any other files in the Google account.

What it does with that access

It writes job matches into its own Sheet and creates CV and cover letter documents in its own folder. It reads that same Sheet back to see which postings have been marked as applied or not of interest.

What it does not do

  • It does not sell, share or transfer any data to third parties.
  • It does not use the data for advertising.
  • It does not send email, apply to jobs, or post anything.
  • It does not access files it did not create.

Where data is kept

Results stay in the Google account that authorized the tool. A small local record of which job postings have already been processed is kept on the operator's own computer.

Removing access

Access can be removed at any time from the Google account's security settings under "Third-party apps and services". Deleting the tool's Sheet, folder and documents removes everything it created.

Google API data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
